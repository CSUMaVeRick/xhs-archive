# 📕 XHS Archive · 小红书笔记归档

> 一个把小红书笔记「一键保存到本地」的浏览器插件，图片、视频、文字全部存到你自己电脑的文件夹里，**不需要联网也能看**。纯本地运行，离线可用，没有服务器、不上传任何数据。

---

## 它帮你做什么？

逛小红书看到想收藏的内容，点一下就能存到本地：

- ✅ **图文 / 视频笔记**都能存
- ✅ 自动整理成 **日期 → 笔记文件夹** 的结构
- ✅ 额外生成一个 **离线可看的网页卡片**（`index.html`），双击就能像刷小红书一样看
- ✅ 保留**标题、作者、发布/归档时间、话题标签、IP 属地、点赞/收藏/评论/分享数、正文**等元数据
- ✅ 视频可按 **最高画质 / 1080P / 720P / 仅封面** 存储
- ✅ 自带一个**归档管理页**：搜索、浏览、离线预览所有已归档的笔记
- ✅ 在笔记页右下角有个**悬浮工具栏**，不打扰你浏览

归档之后你的笔记就是一堆**完整的文件夹**，图片、视频、文字都在里面，不怕原帖删除或失效。

## 支持的浏览器

使用 **Chrome 内核**的主流浏览器均可：

- Google Chrome
- Microsoft Edge
- 其他基于 Chromium 的浏览器（如 Brave）

> 依赖浏览器底层的「文件系统访问 API（File System Access API）」，**Firefox / Safari 暂不支持**。

## 怎么安装？（一次性，约 30 秒）

1. 下载/克隆本仓库到本地一个**不会被删除**的文件夹。
2. 打开浏览器，输入 `chrome://extensions` 并回车。
3. 打开右上角的 **「开发者模式」** 开关。
4. 点击左上角的 **「加载已解压的扩展程序」**。
5. 选择本项目文件夹（就是包含 `manifest.json` 的那个文件夹），完成。

现在浏览器右上角会出现一个 📕 图标。

> ⚠️ 不要移动或删除解压出来的文件夹，否则扩展会失效。
> 如果修改了代码，回到 `chrome://extensions` 点一下扩展卡片上的「重新加载」即可生效。

## 怎么使用？

### 方式一：在笔记页直接归档（最方便）

打开任意一篇小红书笔记，页面右侧会出现一个**竖向细长工具栏**：

- **📥**：一键归档**当前**这篇笔记
- **⟨**：展开/收起详情面板

点击 📥 后会自动把该笔记保存到你的归档目录。

> 第一次使用需要**选择一次归档目录**，之后默认走这个目录。

### 方式二：通过弹窗归档

点右上角的 📕 图标，在弹窗中：

1. 点击 **「选择 / 切换归档目录」**，挑一个放笔记的文件夹（会**记住**，下次不用重选）。
2. 选好 **视频保存画质**。
3. 点击 **「归档当前笔记」**。

### 方式三：开放「归档管理」页

点弹窗里的 **「打开归档管理」**（或右键扩展图标 → 选项），支持：

- 选择归档根目录，自动遍历并列出所有已归档笔记
- 按**标题 / 标签 / 作者**搜索
- 点击任意笔记 → 右侧抽屉在线预览（图片、视频、数据统计、原帖链接）

## 归档后长什么样？

假设归档根目录是 `D:\xhs-archive`，归档日期是 `2024-06-01`，笔记 id 为 `64a1b2...`，标题为「周末露营好物」：

```
D:\xhs-archive\
└── 2024-06\                      ← 归档月份
    └── 2024-06-01\               ← 归档日期
        └── 64a1b2..._周末露营好物\   ← 笔记文件夹（id + 标题）
            ├── metadata.json     ← 完整元数据（JSON）
            ├── index.html        ← 离线可看的卡片页，双击即可浏览
            ├── images\           ← 图片（按顺序命名）
            │   ├── 01.jpg
            │   ├── 02.jpg
            │   └── ...
            └── video\            ← 视频（可选）
                └── video.mp4
```

打开某个 `index.html` 就能离线查看该笔记 —— 即使原帖已被删除。

## 它是怎么工作的？

纯前端，没有后端。核心逻辑大致是：

1. **抓取数据**：拦截页面请求，从小红书返回的笔记 API 数据中提取结构化信息（`content/network.js`）。
2. **多重兜底**：如果 API 拿不到，依次回退到页面里的 `__INITIAL_STATE__` 全局状态、再到直接扫描 DOM（`content/extract.js`），尽量提高成功率、抗改版。
3. **下载到本地**：用浏览器的「文件系统访问 API」让你**选一次目录**，然后把图片、视频、`metadata.json`、离线卡片页直接写进你选的文件夹（`background.js` / `content/archive.js`）。
4. **防盗链处理**：通过 `declarative_net_request`（`rules.json`）给图片 CDN 请求补上 `Referer` / `Origin`，绕过图片 hotlink 限制，不弹浏览器下载框、静默完成。

### 项目结构

```
xhs-dev/
├── manifest.json            # 扩展配置（Manifest V3）
├── rules.json               # 防盗链规则（给 CDN 补 Referer/Origin）
├── background.js            # 后台 Service Worker：静默归档到磁盘
├── popup.html/.js/.css      # 扩展弹窗（选目录、设画质、一键归档）
├── manage.html/.js/.css     # 归档管理页（搜索 / 浏览 / 离线预览）
└── content/
    ├── network.js           # 拦截 fetch/XHR，捕获笔记 API 数据
    ├── extract.js           # 数据抽取：API > __INITIAL_STATE__ > DOM
    ├── archive.js           # 页面内直接归档（File System Access）
    ├── card.js              # 共享的离线卡片模板
    ├── main.js              # 注入的悬浮工具栏 + 详情面板 UI
    └── debug-panel.css      # 调试面板样式
```

代码全部原生 JavaScript，**无需 `npm install`、无需构建**，直接加载即可使用。

## 常见问题

**Q：为什么有时候「归档」提示抓不到笔记？**
小红书页面结构会不定期改版，旧的选择器可能失效。可先**在详情面板里展开「调试信息」**看看走的是哪条抓取路径（API / STATE / DOM），多半能定位问题。

**Q：归档目录换了电脑或清了浏览器数据，之前选的目录还有效吗？**
目录「句柄」保存在浏览器本地的 IndexedDB 里。如果浏览器数据被清、或换电脑，重新选一次目录即可；已经归档到磁盘的文件不受影响。

**Q：可以批量归档吗？**
当前版本是**逐篇**归档的（「当前这篇笔记」）。一次操作存一篇。

**Q：视频保存失败 / 只有封面？**
常见原因是该视频没有能稳定下载的地址（尤其是刚发布、或分辨率选项缺失）。可在弹窗里设为「仅封面」或「720P 标准」再试。

**Q：会不会上传我的数据 / 需要登录？**
不会。所有数据都在**你本地浏览器和本地文件夹**里，**不经过任何服务器**。浏览小红书仍要正常登录小红书账号，但这是小红书自己的登录，与插件无关。
